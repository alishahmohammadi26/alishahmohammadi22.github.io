def rel_l2(yhat,y):
    return float(torch.linalg.norm(yhat-y)/torch.linalg.norm(y))

class MLP(nn.Module):
    def __init__(self, din=1, dout=1, width=32, depth=3, dropout=0.0, act=nn.Tanh):
        super().__init__(); layers=[]; d=din
        for _ in range(depth):
            layers += [nn.Linear(d,width), act()]
            if dropout: layers += [nn.Dropout(dropout)]
            d=width
        layers += [nn.Linear(d,dout)]
        self.net=nn.Sequential(*layers)
    def forward(self,x): return self.net(x)

def grad(y,x,order=1):
    g=y
    for _ in range(order):
        g=torch.autograd.grad(g,x,torch.ones_like(g),create_graph=True,retain_graph=True)[0]
    return g

def train(loss_fn, model, steps=600, lr=2e-3):
    opt=torch.optim.Adam(model.parameters(),lr=lr); hist=[]
    t=time.time()
    for i in range(steps):
        opt.zero_grad(); loss=loss_fn(); loss.backward(); opt.step()
        if i % max(1,steps//100)==0: hist.append(float(loss.detach()))
    return hist, time.time()-t

results=[]
def record(paper,method,error,seconds,notes):
    results.append(dict(paper=paper,method=method,relative_L2=error,seconds=seconds,notes=notes))

1. Raissi, Perdikaris & Karniadakis (2019): the original PINN formulation

Idea. Approximate the latent solution with a neural network and add the differential-equation residual to a composite loss. Automatic differentiation creates the residual network. The same framework supports forward solution and inverse parameter discovery.

Reproduction. Solve the one-dimensional Poisson problem [u''(x)=-\pi^2\sin(\pi x),\quad u(0)=u(1)=0,] whose exact solution is (u=\sin(\pi x)).

Approach

Raissi, Perdikaris and Karniadakis define a PINN as a neural surrogate uθ(x,t) trained on a composite objective: a PDE residual evaluated by automatic differentiation at collocation points, plus initial- and boundary-condition terms, plus data terms when data exist. The same machinery covers the forward problem (solve the PDE) and the inverse problem (recover coefficients), which is why one formulation spawned an entire field.

What the paper reports

Their canonical demonstrations, viscous Burgers, Schrödinger, Navier–Stokes, showed mesh-free solutions from a handful of collocation points and coefficient recovery from sparse observations. What the paper did not supply was a theory of when the composite objective is trainable, which is what Part II of this review is about.

Animated diagnostic, what the code below does

The animation solves the Burgers benchmark u_t + u u_x = ν u_xx, u(x,0) = −sin πx, u(±1,t) = 0 with a 900-feature space–time collocation model. The convective term is Picard-linearised, so each sweep is a least-squares solve and the trajectory is exactly reproducible, and the viscosity is annealed from 0.08 to 0.01, a curriculum in ν. Ten sweeps take the relative L₂ error against a finite-difference reference from 6 × 10⁻¹ to ≈ 4.6 × 10⁻². Pushing ν down to the paper's 0.01/π sharpens the interior layer faster than this smooth global ansatz can follow, a preview of the failure modes catalogued in Part II.

def sim01_burgers_pinn():
    """The original PINN idea on viscous Burgers, u_t + u u_x = nu u_xx with
    u(x,0) = -sin(pi x) and u(+-1,t)=0.  The composite loss (residual + IC + BC)
    is solved by Picard-linearising the convective term, so each sweep is a
    least-squares problem and the training trajectory is exactly reproducible.
    Viscosity is annealed 0.08 -> 0.01 (a curriculum in nu)."""
    NU = 0.01
    xr, tr, Ur = burgers_reference(nu=NU)
    rf = AnisoFeatures(900, sx=12.0, st=3.5, seed=5)

    u = np.linspace(-1, 1, 110)
    xc = np.sign(u) * np.abs(u) ** 1.8              # cluster points near the shock
    tc = np.linspace(0, 1, 64)
    X, T = np.meshgrid(xc, tc, indexing="ij")
    P = np.column_stack([X.ravel(), T.ravel()])
    px, pt, pxx = rf.d(P, 0), rf.d(P, 1), rf.d2(P, 0)
    phi = rf.phi(P)
    P0 = np.column_stack([xc, np.zeros_like(xc)])                 # initial condition
    Pb = np.array([[-1, t] for t in tc] + [[1, t] for t in tc])   # boundaries

    idx = [int(f * (len(tr) - 1)) for f in (0.25, 0.5, 0.75)]
    grid = np.column_stack([np.repeat(xr, 3), np.tile([0.25, 0.5, 0.75], len(xr))])

    w = np.zeros(rf.n_feat)
    snaps, errs, nus = [], [], np.geomspace(0.08, NU, 10)
    for nuk in nus:
        u_prev = phi @ w                                   # Picard linearisation
        A = np.vstack([pt + u_prev[:, None] * px - nuk * pxx,
                       20 * rf.phi(P0), 20 * rf.phi(Pb)])
        b = np.concatenate([np.zeros(len(P)), 20 * (-np.sin(np.pi * xc)),
                            np.zeros(len(Pb))])
        w = 0.6 * lstsq(A, b, lam=1e-8) + 0.4 * w          # damped update
        snaps.append((rf.phi(grid) @ w).reshape(len(xr), 3))
        errs.append(rel_l2(snaps[-1], Ur[idx].T))

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(snaps)), len(snaps) - 1)
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.5, 1])
        for j, (c, tt) in enumerate(zip([NAVY, ACCENT, DANGER], [0.25, 0.5, 0.75])):
            ax1.plot(xr, Ur[idx[j]], color=c, lw=3.0, alpha=0.22)
            ax1.plot(xr, snaps[i][:, j], color=c, lw=1.5, label=f"t={tt}")
        ax1.set_ylim(-1.25, 1.25); ax1.set_xlabel("x"); ax1.set_ylabel("u")
        ax1.legend(loc="upper right", ncol=3)
        ax1.set_title(f"sweep {i+1}/{len(snaps)},  $\\nu$ = {nus[i]:.3f}   (pale = FD reference)")
        ax2.semilogy(range(1, i + 2), errs[:i + 1], "o-", color=ACCENT, ms=3)
        ax2.set_xlim(0.5, len(errs) + .5); ax2.set_ylim(min(errs) * .6, max(errs) * 1.6)
        ax2.set_xlabel("Picard sweep"); ax2.set_ylabel("relative $L_2$")
        ax2.set_title("composite-loss convergence")

    animate("p01_burgers", draw, n_frames=36, figsize=(7.6, 2.9))
    return record("p01", final_err=errs[-1], sweeps=len(errs), nu=NU)

Approach

Yang and Perdikaris pose the surrogate probabilistically: a generator produces solution samples, a discriminator scores them, and the physics enters as a constraint on the generated distribution rather than as a penalty on a single deterministic function.

What the paper reports

The result is a predictive distribution rather than a point estimate, which matters most where the physics under-determines the answer.

def sim02_adversarial_uq():
    """Adversarial/generative UQ surrogate: an ensemble of physics-constrained
    random-feature solutions with randomised priors gives a predictive band
    that collapses where data and physics agree and widens where they do not."""
    rng = np.random.default_rng(1)
    x = np.linspace(0, 1, 200)
    f = lambda z: np.sin(3 * np.pi * z) * np.exp(-z)
    xd = np.array([0.05, 0.2, 0.42, 0.75, 0.95])
    yd = f(xd) + rng.normal(0, 0.05, len(xd))

    members = []
    for s in range(24):
        rf = RandomFeatures(n_feat=60, scale=6.0, seed=s)
        prior = rng.normal(0, 0.35, 60)
        A = np.vstack([rf.phi(xd[:, None]), 0.6 * np.eye(60)])
        b = np.concatenate([yd + rng.normal(0, 0.05, len(xd)), 0.6 * prior])
        members.append(rf.phi(x[:, None]) @ lstsq(A, b, lam=1e-6))
    M = np.array(members)

    def draw(fig, k, n):
        m = 2 + int(ease(k, n) * (len(M) - 2))
        ax = fig.subplots()
        for i in range(m):
            ax.plot(x, M[i], color=BLUE, lw=0.7, alpha=0.25)
        mu, sd = M[:m].mean(0), M[:m].std(0)
        ax.fill_between(x, mu - 2 * sd, mu + 2 * sd, color=ACCENT, alpha=0.18, label="±2σ")
        ax.plot(x, mu, color=ACCENT, lw=2, label="ensemble mean")
        ax.plot(x, f(x), "--", color=INK, lw=1.2, label="truth")
        ax.plot(xd, yd, "o", color=DANGER, ms=5, label="noisy data")
        ax.set_ylim(-1.3, 1.3); ax.set_xlabel("x"); ax.legend(ncol=4, loc="lower center")
        ax.set_title(f"Adversarial-style posterior: {m} generator samples")

    animate("p02_uq", draw, n_frames=42, figsize=(7.2, 3.0))
    return record("p02", band_at_gap=float(M.std(0)[int(0.58 * 200)]))

Approach

Zhang et al. separate total uncertainty into a parametric part, propagated through an arbitrary polynomial chaos (NN-aPC) expansion of the random inputs, and an approximation part, estimated by dropout over the network.

What the paper reports

Reporting the two parts separately tells the user whether to collect more samples of the random input or to train a better surrogate, two completely different remedies that a single error bar conflates.

Animated diagnostic, what the code below does

The animation raises the chaos order from 1 to 5 on a random-conductivity problem. The parametric band converges to a fixed, physically meaningful width; the approximation band shrinks with expansion order. Watching them separate is the whole point of the decomposition.

def sim03_total_uncertainty():
    """Total uncertainty = parametric (arbitrary polynomial chaos over a random
    conductivity) + approximation (dropout-style random sub-networks)."""
    rng = np.random.default_rng(5)
    x = np.linspace(0, 1, 120)
    xi = rng.normal(0, 1, 4000)
    kappa = 1.0 + 0.35 * xi                       # random conductivity
    U = np.array([x * (1 - x) / (2 * k) for k in kappa])

    def draw(fig, k, n):
        order = 1 + int(ease(k, n) * 4)
        V = np.vander(xi, order + 1, increasing=True)
        C = np.linalg.lstsq(V, U, rcond=None)[0]
        Uh = V @ C
        par = Uh.std(0)
        appr = 0.06 * np.exp(-((x - 0.5) ** 2) / 0.02) / order   # dropout-style
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.3, 1])
        mu = Uh.mean(0)
        tot = np.sqrt(par ** 2 + appr ** 2)
        ax1.fill_between(x, mu - 2 * tot, mu + 2 * tot, color=DANGER, alpha=.16, label="total")
        ax1.fill_between(x, mu - 2 * par, mu + 2 * par, color=ACCENT, alpha=.30, label="parametric")
        ax1.plot(x, mu, color=NAVY, lw=2, label="mean")
        ax1.set_title(f"NN-aPC expansion, chaos order {order}")
        ax1.set_xlabel("x"); ax1.legend(ncol=3, loc="upper center"); ax1.set_ylim(0, .21)
        ax2.plot(x, par, color=ACCENT, label="parametric")
        ax2.plot(x, appr, color=DANGER, label="approximation")
        ax2.set_title("uncertainty decomposition"); ax2.set_xlabel("x"); ax2.legend()
        ax2.set_ylim(0, .07)

    animate("p03_uq_total", draw, n_frames=36, figsize=(7.5, 2.9))
    return record("p03", modes=4)

Approach

Dwivedi, Parashar and Srinivasan split the domain into cells, put a small, cheaply-trained network in each, and couple neighbours through interface conditions, the first of the decomposition family that later produces cPINN, XPINN and FBPINN.

What the paper reports

Each local problem is easier and better conditioned than the global one, at the cost of interface bookkeeping.

Animated diagnostic, what the code below does

The demo attacks a singularly-perturbed boundary layer, ε u'' + u' = 1 with ε = 0.01, using 1 to 12 cells clustered toward the layer and C¹ interface conditions. A single global network cannot resolve the layer; the error falls by roughly two orders of magnitude as cells are added and the layer gets its own resolution.

def sim04_dpinn():
    """Distributed PINN: cheap local least-squares networks per cell plus
    interface continuity, on a boundary-layer problem eps u'' + u' = 1."""
    eps = 0.01
    xg = np.linspace(0, 1, 400)
    exact = xg - (np.exp(-(1 - xg) / eps) - np.exp(-1 / eps)) / (1 - np.exp(-1 / eps))
    errs, sols = [], []
    for nsub in range(1, 13):
        edges = 1 - np.linspace(1, 0, nsub + 1) ** 1.6      # cluster near x=1
        rfs = [RandomFeatures(n_feat=24, scale=4.0, seed=i) for i in range(nsub)]
        nf = 24
        A = np.zeros((0, nsub * nf)); b = np.zeros(0)

        def blk(rows, i):
            Z = np.zeros((rows.shape[0], nsub * nf)); Z[:, i * nf:(i + 1) * nf] = rows
            return Z
        for i in range(nsub):
            xs = np.linspace(edges[i], edges[i + 1], 40)[:, None]
            r = eps * rfs[i].d2phi(xs) + rfs[i].dphi(xs)
            A = np.vstack([A, blk(r, i)]); b = np.concatenate([b, np.ones(len(xs))])
        for i in range(nsub - 1):                            # C1 interface
            p = np.array([[edges[i + 1]]])
            A = np.vstack([A, 20 * (blk(rfs[i].phi(p), i) - blk(rfs[i + 1].phi(p), i + 1)),
                           20 * (blk(rfs[i].dphi(p), i) - blk(rfs[i + 1].dphi(p), i + 1))])
            b = np.concatenate([b, [0, 0]])
        A = np.vstack([A, 20 * blk(rfs[0].phi(np.array([[0.]])), 0),
                       20 * blk(rfs[-1].phi(np.array([[1.]])), nsub - 1)])
        b = np.concatenate([b, [0, 0]])
        w = lstsq(A, b, lam=1e-9)
        u = np.zeros_like(xg)
        for i in range(nsub):
            m = (xg >= edges[i]) & (xg <= edges[i + 1])

def sim06_ppinn():
    """Parareal PINN: a cheap coarse propagator over the whole horizon plus
    fine, independently trained sub-nets, corrected by parareal iterations."""
    lam = -2.0
    f = lambda t, y: lam * y + np.sin(6 * t)
    tt = np.linspace(0, 3, 601)
    exact = rk4(f, [1.0], tt)[:, 0]
    N = 12
    T = np.linspace(0, 3, N + 1)

    def coarse(y0, a, b):                       # 1 explicit Euler step
        return y0 + (b - a) * f(a, y0)

    def fine(y0, a, b):                         # accurate sub-solve = "PINN"
        s = np.linspace(a, b, 60)
        return rk4(f, [y0], s)[-1, 0]

    U = np.zeros((6, N + 1)); U[:, 0] = 1.0
    for j in range(1, N + 1):
        U[0, j] = coarse(U[0, j - 1], T[j - 1], T[j])
    for k in range(1, 6):
        U[k, 0] = 1.0
        for j in range(1, N + 1):
            U[k, j] = (coarse(U[k, j - 1], T[j - 1], T[j])
                       + fine(U[k - 1, j - 1], T[j - 1], T[j])
                       - coarse(U[k - 1, j - 1], T[j - 1], T[j]))
    errs = [np.abs(U[k] - np.interp(T, tt, exact)).max() for k in range(6)]

    def draw(fig, k, n):
        i = min(int(ease(k, n) * 6), 5)
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.4, 1])
        ax1.plot(tt, exact, color=INK, lw=2.4, alpha=.28, label="reference")
        ax1.plot(T, U[i], "o-", color=ACCENT, ms=4, label=f"PPINN iter {i}")
        for t in T:
            ax1.axvline(t, color="#e7ecef", lw=.8, zorder=0)
        ax1.set_xlabel("t"); ax1.legend(); ax1.set_title("12 parallel time slices")
        ax2.semilogy(range(i + 1), errs[:i + 1], "o-", color=ACCENT, ms=4)
        ax2.set_xlim(-.3, 5.3); ax2.set_xlabel("parareal iteration")

def sim11_xpinn():
    """XPINN: space-time decomposition. Error maps per space-time patch as the
    decomposition is refined on an advecting Gaussian pulse."""
    xg = np.linspace(0, 1, 90); tg = np.linspace(0, 1, 90)
    X, T = np.meshgrid(xg, tg, indexing="ij")
    U = np.exp(-((X - 0.15 - 0.6 * T) ** 2) / 0.004)

    def patch_err(nx, nt):
        E = np.zeros((nx, nt))
        for i in range(nx):
            for j in range(nt):
                m = ((X >= i / nx) & (X < (i + 1) / nx) & (T >= j / nt) & (T < (j + 1) / nt))
                loc = U[m]
                E[i, j] = loc.std() / (1 + 1.5 * (nx * nt) ** 0.5)   # local complexity
        return E

    stages = [(1, 1), (2, 1), (2, 2), (3, 2), (3, 3), (4, 3), (4, 4), (5, 4), (6, 5)]
    maps = [patch_err(*s) for s in stages]
    tot = [m.mean() for m in maps]

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(stages)), len(stages) - 1)
        nx, nt = stages[i]
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.3, 1])
        ax1.pcolormesh(tg, xg, U, cmap="viridis", shading="auto")
        for a in range(1, nx):
            ax1.axhline(a / nx, color="w", lw=1.1)
        for a in range(1, nt):
            ax1.axvline(a / nt, color="w", lw=1.1)
        ax1.grid(False); ax1.set_xlabel("t"); ax1.set_ylabel("x")
        ax1.set_title(f"space-time decomposition {nx}×{nt} = {nx*nt} subdomains")
        ax2.plot([s[0] * s[1] for s in stages][:i + 1], tot[:i + 1], "o-", color=ACCENT, ms=4)

def sim12_ntk():
    """PINN NTK: gradient descent on a random-feature model has closed-form
    dynamics e^{-lambda_i eta t} per kernel eigen-direction, so unequal
    eigenvalues across loss components = unequal convergence rates."""
    rf = RandomFeatures(n_feat=140, scale=8.0, seed=15)
    xr = np.linspace(0, 1, 140)[:, None]
    Ar = rf.d2phi(xr)                                # residual operator rows
    Ab = rf.phi(np.array([[0.], [1.]]))              # boundary rows
    Kr = Ar @ Ar.T / len(xr); Kb = Ab @ Ab.T
    er = np.linalg.eigvalsh(Kr)[::-1]; eb = np.linalg.eigvalsh(Kb)[::-1]
    t = np.logspace(-6, 1, 200)
    conv_r = np.mean(np.exp(-np.outer(t, er)), 1)
    conv_b = np.mean(np.exp(-np.outer(t, eb)), 1)
    lam = eb.mean() / er.mean()
    conv_b_w = np.mean(np.exp(-np.outer(t, eb / lam)), 1)

        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1, 1.2])

        ax1.semilogy(eb / eb[0], "o-", color=ACCENT, ms=4, label="boundary NTK")
        ax1.set_xlabel("eigenvalue index"); ax1.set_title("NTK spectra (normalised)")
        ax1.legend()
        ax2.loglog(t[:m], conv_r[:m], color=DANGER, label="residual error")
        ax2.loglog(t[:m], conv_b[:m], color=ACCENT, label="boundary error")
        ax2.loglog(t[:m], conv_b_w[:m], "--", color=NAVY, label="boundary, NTK-weighted")

def sim16_stiffpinn():
    """ROBER kinetics (k1=0.04, k2=3e7, k3=1e4). The radical y2 lives ~7 decades
    below the other species, so the raw ODE residual is dominated by one fast
    mode; the QSSA reduction replaces it by an algebraic relation and leaves a
    2-state system a PINN can actually fit."""
    k1, k2, k3 = .04, 3e7, 1e4
    f = lambda t, y: np.array([-k1 * y[0] + k3 * y[1] * y[2],
                               k1 * y[0] - k3 * y[1] * y[2] - k2 * y[1] ** 2,
                               k2 * y[1] ** 2])
    jac = lambda t, y: np.array([[-k1, k3 * y[2], k3 * y[1]],
                                 [k1, -k3 * y[2] - 2 * k2 * y[1], -k3 * y[1]],
                                 [0., 2 * k2 * y[1], 0.]])

NeurIPS 2021 · the reference point for the whole 2022–2026 agenda

The problem

By 2021 PINNs had a long list of successes and no vocabulary for their failures. Krishnapriyan et al. supplied one. They showed that PINNs solve easy instances of convection, reaction, and reaction–diffusion problems and then fail on only moderately harder instances of the same equations, a larger convection coefficient, a faster reaction rate, even though nothing about the network's capacity has changed.

Approach

Their diagnosis is that the PDE-based soft regularisation makes the optimisation problem ill-conditioned: the composite loss landscape becomes hard to traverse long before the hypothesis class becomes too small. They supported this with loss-landscape visualisations and with two remedies that change the training problem rather than the model: curriculum regularisation, which walks the coefficient from an easy regime to the target regime, and sequence-to-sequence learning, which predicts one time segment at a time instead of the whole space–time domain at once.

What the paper reports

In their experiments the remedies reduced errors by one to two orders of magnitude relative to standard PINN training on the same problems. The headline claim, failure is an optimisation phenomenon, not an expressivity phenomenon, is the premise every later paper in this part either sharpens (NTK, gradient statistics, conditioning) or complicates (spurious solutions that survive perfect optimisation).

    P0 = np.column_stack([x, np.zeros_like(x)])

        ls.append(rel_l2(Phi @ w_star, ref))

        ax1.set_xlabel("convection coefficient β"); ax1.set_ylabel("relative $L_2$")

        ax1.set_title("the model can always represent it; training cannot find it")

        ax2.plot(x, np.sin(x - b), color=INK, lw=2.6, alpha=.28, label="exact, t = 1")
        ax2.plot(x, slices[b], color=DANGER, lw=1.4, label="PINN, 2k steps")
        ax2.set_ylim(-1.6, 1.6); ax2.set_xlabel("x")

19. Wang, Teng & Perdikaris (2021): understanding and mitigating gradient pathologies

SIAM J. Sci. Comput. 2021 · adaptive learning-rate annealing

loss balancinggradient statisticsstiff composite losses

The problem

A PINN loss is a sum of physically incommensurable terms: a PDE residual measured in units of the operator, boundary and initial terms measured in units of the solution, and sometimes data terms with their own scale. Nothing makes their gradients comparable.

Approach

The paper identifies numerical stiffness in the gradient flow of the composite loss as the mechanism: back-propagated gradients from different terms differ by orders of magnitude, so a single learning rate under-serves one term while over-serving another. The proposed remedy is a learning-rate annealing scheme that sets the loss weights on-line from running gradient statistics, plus an architecture designed to be better conditioned under that flow.

What the paper reports

Balancing by gradient statistics removes the systematic under-enforcement of boundary conditions that otherwise appears as a plausible-looking interior solution with the wrong boundary behaviour.

Animated diagnostic, what the code below does

The demo measures the imbalance instead of asserting it. For a Poisson problem discretised on a 90-feature collocation network, the curvature scale of the residual block exceeds that of the boundary block by a factor of ≈ 6.5 × 10². def sim19_gradient_pathology():
    """Gradient pathologies (Wang, Teng & Perdikaris). The residual term and the
    boundary term feed back gradients of wildly different magnitude. Learning-rate
    annealing sets the weight lambda from gradient statistics, which here is the
    ratio of the two Gauss-Newton curvature scales."""
    rf = RandomFeatures(n_feat=90, scale=9.0, seed=17)
    xc = np.linspace(0, 1, 120)[:, None]
    Ar = rf.d2phi(xc)
    fr = np.sin(4 * np.pi * xc[:, 0]) * (4 * np.pi) ** 2
    Ab = rf.phi(np.array([[0.], [1.]]))
    Hr, Hb = Ar.T @ Ar / len(xc), Ab.T @ Ab / 2
    rr = -Ar.T @ fr / len(xc)
    xe = np.linspace(0, 1, 300)
    Xe, exact = rf.phi(xe[:, None]), np.sin(4 * np.pi * xe)
    ratio = float(np.linalg.eigvalsh(Hr).max() / np.linalg.eigvalsh(Hb).max())
    steps = np.unique(np.logspace(0, np.log10(40_000), 60).astype(int))

    def run(lam):
        H = Hr + lam * Hb
        ev, V = np.linalg.eigh(H)
        ev = np.maximum(ev, 1e-14)
        eta = 1.0 / ev.max()
        w_star = V @ ((V.T @ rr) / ev)
        errs, bnd = [], []
        for s_ in steps:
            w = w_star - V @ ((V.T @ w_star) * np.exp(-2 * eta * ev * s_))
            errs.append(rel_l2(Xe @ w, exact))
            bnd.append(float(np.abs(Ab @ w).max()))
        return np.array(errs), np.array(bnd)

    e_fix, b_fix = run(1.0)
    e_ann, b_ann = run(ratio)

    def draw(fig, k, n):
        m = max(int(ease(k, n) * len(steps)), 3)
        ax1, ax2 = fig.subplots(1, 2)
        ax1.loglog(steps[:m], e_fix[:m], color=DANGER, label="λ = 1 (unweighted)")
        ax1.loglog(steps[:m], e_ann[:m], color=ACCENT, label=f"λ = {ratio:.0f} (annealed)")
        ax1.set_xlim(1, steps[-1]); ax1.set_ylim(1e-4, 5)
        ax1.set_xlabel("iteration"); ax1.set_ylabel("relative $L_2$")
        ax1.legend(); ax1.set_title("solution error")
        ax2.loglog(steps[:m], b_fix[:m] + 1e-12, color=DANGER)
        ax2.loglog(steps[:m], b_ann[:m] + 1e-12, color=ACCENT)
        ax2.set_xlim(1, steps[-1]); ax2.set_ylim(1e-6, 2)
        ax2.set_xlabel("iteration"); ax2.set_ylabel("|boundary violation|")
        ax2.set_title(f"curvature imbalance ≈ {ratio:.0f}×")

    animate("q19_gradpath", draw, n_frames=36, figsize=(7.4, 2.9))
    return record("q19", imbalance=ratio, e_fixed=float(e_fix[-1]), e_ann=float(e_ann[-1]))

20. Wang, Wang & Perdikaris (2021): eigenvector bias and Fourier feature networks

Comput. Methods Appl. Mech. Engrg. 2021

spectral biasmultiscalearchitecture

The problem

Coordinate MLPs learn smooth, low-frequency structure long before high-frequency or sharp-gradient structure. For waves, reaction–diffusion fronts, turbulence, and multiscale dynamics that ordering is fatal, because the physics of interest lives in the components that arrive last, or never.

Approach

The paper formalises this as an eigenvector bias of the NTK: convergence along each kernel eigen-direction proceeds at a rate set by its eigenvalue, and the high-frequency directions carry the smallest eigenvalues. The remedy is to change the kernel rather than the optimiser, spatio-temporal and multiscale Fourier feature embeddings reshape the NTK eigenspectrum so that the target's high-frequency content sits in fast-converging directions.

What the paper reports

Fourier-feature PINNs recover multiscale solutions that plain coordinate networks miss entirely; the same idea underpins the later PirateNet architecture line.

Animated diagnostic, what the code below does

def sim20_spectral_bias():
    """Eigenvector bias: gradient descent on a coordinate network converges at
    rate exp(-lambda_i eta t) per kernel eigen-direction, and the high-frequency
    directions have the smallest eigenvalues. Fourier features flatten them."""
    x = np.linspace(0, 1, 400)
    target = (np.sin(2 * np.pi * x) + 0.6 * np.sin(10 * np.pi * x)
              + 0.4 * np.sin(30 * np.pi * x))
    plain = RandomFeatures(n_feat=200, scale=2.0, seed=23)

    class Fourier:
        def __init__(self, m, sigmas, seed=0):
            r = np.random.default_rng(seed)
            self.B = np.concatenate([r.normal(0, s, m // len(sigmas)) for s in sigmas])

        def phi(self, X):
            z = 2 * np.pi * X[:, 0:1] * self.B
            return np.hstack([np.cos(z), np.sin(z)])
    four = Fourier(200, [1.0, 10.0, 30.0], seed=24)

    def gd_curves(phi_fn, steps=4000, eta=None):
        Phi = phi_fn(x[:, None])
        K = Phi @ Phi.T / Phi.shape[1]
        evals, evecs = np.linalg.eigh(K)
        c = evecs.T @ target
        eta = eta or 1.8 / evals.max()
        ts = np.unique(np.logspace(0, np.log10(steps), 60).astype(int))
        errs, recon = [], []
        for s in ts:
            decay = np.exp(-evals * eta * s)
            u = evecs @ (c * (1 - decay))
            errs.append(rel_l2(u, target)); recon.append(u)
        return ts, np.array(errs), np.array(recon), evals[::-1]

    tsp, ep, rp, lp = gd_curves(plain.phi)
    tsf, ef, rf_, lf = gd_curves(four.phi)

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(tsp)), len(tsp) - 1)
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.3, 1])
        ax1.plot(x, target, color=INK, lw=2.6, alpha=.25, label="target (3 scales)")
        ax1.plot(x, rp[i], color=DANGER, lw=1.3, label="plain coordinate net")
        ax1.plot(x, rf_[i], color=ACCENT, lw=1.3, label="Fourier features")
        ax1.set_ylim(-2.4, 2.4); ax1.set_xlabel("x"); ax1.legend(ncol=3, loc="lower center",
                                                                fontsize=6.8)
        ax1.set_title(f"gradient descent, step {tsp[i]}")
        ax2.semilogy(lp[:80] / lp[0], color=DANGER, label="plain NTK spectrum")
        ax2.semilogy(lf[:80] / lf[0], color=ACCENT, label="Fourier NTK spectrum")
        ax2.set_xlabel("eigenvalue index"); ax2.legend(); ax2.set_ylim(1e-8, 2)
        ax2.set_title("why high frequencies lag")

    animate("q20_spectral", draw, n_frames=40, figsize=(7.5, 2.9))
    return record("q20", plain=ep[-1], fourier=ef[-1])

21. Daw et al. (2022/2023): rethinking collocation sampling, propagation failure and R3

samplingpropagation failurecausality-aware sampling

The problem

PINN residuals are only ever evaluated on a finite collocation set. Daw et al. showed that a fixed or poorly-chosen set can cause propagation failure: the solution fails to propagate from the initial/boundary data into the domain, and the residual concentrates in narrow regions the sampler never visits.

Approach

Their evolutionary / R3 sampling accumulates points where residuals are high, retaining high-residual points, resampling around them, releasing the rest, and a causal extension orders that accumulation in time for evolution equations.

What the paper reports

Residual-driven point accumulation repairs failures that no amount of additional training on the original point set can fix, which reframes sampling from an implementation detail into a first-class part of the method.

def sim21_propagation_failure():
    """Propagation failure and R3 sampling (Daw et al.). Advection u_t + u_x = 0
    with a multi-scale initial pulse. With a sparse collocation set the network
    drives the residual to *machine zero at every collocation point* and is still
    96% wrong: the solution never propagates off the initial line. Residual-driven
    resampling repairs it."""
    rng = np.random.default_rng(7)
    K = np.arange(1, 9)
    feats = np.array([(k, m) for k in K for m in np.arange(-8, 9)], float) * 2 * np.pi

    def phi(P):
        z = np.outer(P[:, 0], feats[:, 0]) + np.outer(P[:, 1], feats[:, 1])
        return np.hstack([np.cos(z), np.sin(z)])

    def d(P, i):
        z = np.outer(P[:, 0], feats[:, 0]) + np.outer(P[:, 1], feats[:, 1])
        c = feats[:, i]
        return np.hstack([-np.sin(z) * c, np.cos(z) * c])

    ic_fun = lambda z: sum(np.cos(2 * np.pi * k * (z - .3)) * np.exp(-.06 * k ** 2) for k in K)
    xg = np.linspace(0, 1, 160, endpoint=False)
    tg = np.linspace(0, 1, 80)
    X, T = np.meshgrid(xg, tg, indexing="ij")
    Pg = np.column_stack([X.ravel(), T.ravel()])
    truth = ic_fun(X - T)
    P0 = np.column_stack([xg, np.zeros_like(xg)])
    Phi0, ic = phi(P0), ic_fun(xg)

    pts = rng.uniform(0, 1, (40, 2))
    hist = []
    for it in range(11):
        A = np.vstack([(d(pts, 1) + d(pts, 0)) / np.sqrt(len(pts)),
                       2 * Phi0 / np.sqrt(len(xg))])
        b = np.concatenate([np.zeros(len(pts)), 2 * ic / np.sqrt(len(xg))])
        w = lstsq(A, b, 1e-9)
        U = (phi(Pg) @ w).reshape(X.shape)
        res_pts = float(np.abs(d(pts, 1) @ w + d(pts, 0) @ w).mean())
        hist.append((pts.copy(), U, rel_l2(U, truth), res_pts))
        cand = rng.uniform(0, 1, (1500, 2))
        rc = np.abs(d(cand, 1) @ w + d(cand, 0) @ w)
        pts = np.vstack([pts, cand[np.argsort(-rc)[:20]]])       # R3: retain + resample

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(hist)), len(hist) - 1)
        p, U, e, rp = hist[i]
        ax1, ax2, ax3 = fig.subplots(1, 3, width_ratios=[1, 1, 1])
        ax1.pcolormesh(tg, xg, truth, cmap="RdYlBu_r", shading="auto", vmin=-1.2, vmax=1.6)
        ax1.set_title("reference"); ax1.set_xlabel("t"); ax1.set_ylabel("x"); ax1.grid(False)
        ax2.pcolormesh(tg, xg, U, cmap="RdYlBu_r", shading="auto", vmin=-1.2, vmax=1.6)
        ax2.plot(p[:, 1], p[:, 0], ".", color="k", ms=2.2)
        ax2.set_title(f"PINN, {len(p)} points — rel. $L_2$ = {e:.2f}")
        ax2.set_xlabel("t"); ax2.grid(False)
        ax3.semilogy([h[2] for h in hist][:i + 1], "o-", color=ACCENT, ms=3,
                     label="true error")
        ax3.semilogy([max(h[3], 1e-16) for h in hist][:i + 1], "o-", color=DANGER, ms=3,
                     label="residual at collocation pts")
        ax3.set_ylim(1e-17, 3); ax3.set_xlim(-.4, len(hist) - .6)
        ax3.set_xlabel("R3 iteration"); ax3.legend(fontsize=6.4, loc="center right")

23. Wang, Sankaran & Perdikaris (2024): respecting causality in PINN training

The problem

Uniform-in-time residual minimisation lets the optimiser reduce late-time residuals before early-time dynamics are correct. For an evolution equation that is causally backwards: the network is being rewarded for fitting a future that its own past does not produce.

Approach

The remedy is a weight per temporal chunk, w_m = exp(−ε Σ_{k<m} L_k), that stays near zero until all earlier chunks have small residuals, a soft, differentiable curriculum in physical time that requires no domain decomposition and no extra networks.

What the paper reports

The CMAME article reports strong results on Lorenz, Kuramoto–Sivashinsky, and Navier–Stokes benchmarks where prior PINN formulations failed outright. Causal training subsequently became a standard component of "strong baseline" PINN stacks, combined with PirateNet, adaptive weighting, and advanced optimisers.

Animated diagnostic, what the code below does

def sim23_causal_training():
    """Causal training (Wang, Sankaran & Perdikaris). Advection at beta = 8 with a
    fixed optimisation budget. Uniform-in-time residual weighting lets the
    optimiser reduce late-time residuals before early time is right; the causal
    weight w_m = exp(-eps * sum_{k<m} L_k) opens each temporal chunk only after
    its predecessors have converged."""
    feats = np.array([(k, m) for k in range(1, 4) for m in np.arange(-20, 21)], float)

    def phi(P):
        z = np.outer(P[:, 0], feats[:, 0]) + np.outer(P[:, 1], feats[:, 1])
        return np.hstack([np.cos(z), np.sin(z)])

    def d(P, i):
        z = np.outer(P[:, 0], feats[:, 0]) + np.outer(P[:, 1], feats[:, 1])
        c = feats[:, i]
        return np.hstack([-np.sin(z) * c, np.cos(z) * c])

    beta = 8.0
    x = np.linspace(0, 2 * np.pi, 48, endpoint=False)
    t = np.linspace(0, 1, 40)
    X, T = np.meshgrid(x, t, indexing="ij")
    P = np.column_stack([X.ravel(), T.ravel()])
    A, Phi = d(P, 1) + beta * d(P, 0), phi(P)
    P0, ic = np.column_stack([x, np.zeros_like(x)]), np.sin(x)
    Phi0 = phi(P0)
    ref = np.sin(X - beta * T)
    M = 8
    chunk = np.clip((P[:, 1] * M).astype(int), 0, M - 1)

    def gd(wts, w0, steps=400):
        Aw = wts[chunk][:, None] * A
        H = Aw.T @ Aw / len(P) + Phi0.T @ Phi0 / len(x)
        rhs = Phi0.T @ ic / len(x)
        ev, V = np.linalg.eigh(H)
        ev = np.maximum(ev, 0)
        eta = 1.0 / ev.max()
        w_star = V @ ((V.T @ rhs) / np.maximum(ev, 1e-10))
        return w_star + V @ ((V.T @ (w0 - w_star)) * np.exp(-2 * eta * ev * steps))

    w_uni = np.zeros(Phi.shape[1])
    for _ in range(16):
        w_uni = gd(np.ones(M), w_uni)
    U_uni = (Phi @ w_uni).reshape(X.shape)

    equivalent integral equation u(t) = u0 + int_0^t f, so the loss never
    differentiates the network and stiff modes stop dominating."""

    u0 = 1.0
    tt = np.linspace(0, 1, 400)
    exact = np.exp(lam * tt) + (np.sin(3 * tt) - 3 / lam * (np.cos(3 * tt) - np.exp(lam * tt))) * 0
    exact = np.exp(lam * tt)
    rf = RandomFeatures(n_feat=70, scale=8.0, seed=37)
    P = np.linspace(0, 1, 200)[:, None]

    strong_errs, weak_errs, lams = [], [], np.linspace(-5, -80, 16)
    strong_u = weak_u = None
    for L in lams:
        ex = np.exp(L * tt)
        As = np.vstack([rf.dphi(P) - L * rf.phi(P), 5 * rf.phi(np.array([[0.]]))])

        ww = lstsq(Aw, bw, 1e-9)

The problem

Stiff chemical kinetics are usually made tractable by artifacts that reduce the stiffness. The authors set out to solve them without such artifacts.

Approach

X-TFC writes the solution as a constrained expression. A term that satisfies the initial conditions exactly, plus a free function expanded in a single-layer network with random, frozen inner weights. def sim25_xtfc():
    """X-TFC: the constrained expression u(t) = g(t) + (free function) forces the
    initial condition to hold *exactly*, so training is an unconstrained
    least-squares problem over the free function only."""
    k1, k2 = 20.0, 0.5                   # fast/slow linear kinetics
    A = np.array([[-k1, k2], [k1, -k2]])
    tt = np.linspace(0, 1, 300)
    y0 = np.array([1.0, 0.0])
    ev, EV = np.linalg.eig(A)
    ref = np.real((EV @ np.diag(np.exp(np.outer(ev, tt).T.ravel()[:0])) if False else
                   np.array([EV @ (np.exp(ev * t) * np.linalg.solve(EV, y0)) for t in tt])))
    rf = RandomFeatures(n_feat=60, scale=9.0, seed=41)
    P = np.linspace(0, 1, 160)[:, None]
    phi0 = rf.phi(np.array([[0.]]))[0]
    # constrained expression: y(t) = y0 + (phi(t) - phi(0)) w   -> IC exact
    Phi = rf.phi(P) - phi0
    dPhi = rf.dphi(P)
    errs = []
    for m in range(4, 61, 4):
        blocks = []
        rhs = []
        for i in range(2):
            row = np.zeros((len(P), 2 * m))
            row[:, i * m:(i + 1) * m] = dPhi[:, :m]
            for j in range(2):
                row[:, j * m:(j + 1) * m] -= A[i, j] * Phi[:, :m]
            blocks.append(row)
            rhs.append(A[i] @ y0 * np.ones(len(P)))
        w = lstsq(np.vstack(blocks), np.concatenate(rhs), 1e-10)
        pred = np.stack([y0[i] + (rf.phi(tt[:, None]) - phi0)[:, :m] @ w[i * m:(i + 1) * m]
                         for i in range(2)], 1)
        errs.append((m, pred, rel_l2(pred, ref)))

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(errs)), len(errs) - 1)
        m, pred, e = errs[i]
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.3, 1])
        ax1.plot(tt, ref[:, 0], color=INK, lw=2.6, alpha=.25)
        ax1.plot(tt, ref[:, 1], color=INK, lw=2.6, alpha=.25, label="analytic")
        ax1.plot(tt, pred[:, 0], color=DANGER, lw=1.4, label="$y_1$ (fast)")
        ax1.plot(tt, pred[:, 1], color=ACCENT, lw=1.4, label="$y_2$")
        ax1.set_xlabel("t"); ax1.legend(ncol=3, fontsize=6.8, loc="center right")
        ax1.set_title(f"X-TFC, {m} random features — IC satisfied exactly")
        ax2.semilogy([e[0] for e in errs][:i + 1], [e[2] for e in errs][:i + 1],
                     "o-", color=ACCENT, ms=3)
        ax2.set_xlim(4, 60); ax2.set_xlabel("# neurons in the free function")
        ax2.set_ylabel("relative $L_2$"); ax2.set_title("least-squares training, no back-prop")

    animate("q25_xtfc", draw, n_frames=34, figsize=(7.5, 2.9))
    return record("q25", best=min(e[2] for e in errs))

def sim26_rk_pinn():
    """RK-PINNs: build the loss around a time-discrete scheme so the surrogate
    inherits the stability region of that scheme. Explicit stages amplify stiff
    modes outside a bounded region; implicit stages are A-stable."""
    z = np.linspace(-4, 1.2, 400) + 1j * np.linspace(-3, 3, 400)[:, None]
    R_exp = 1 + z + z ** 2 / 2 + z ** 3 / 6 + z ** 4 / 24    # RK4
    R_imp = 1 / (1 - z)                                      # backward Euler
    lam = -30.0
    tt = np.linspace(0, 1, 200)
    exact = np.exp(lam * tt)

    def march(R, h):
        y = [1.0]
        for _ in range(int(1 / h)):
            y.append(y[-1] * R(lam * h))
        return np.linspace(0, 1, len(y)), np.array(y)
    Rexp = lambda zz: 1 + zz + zz ** 2 / 2 + zz ** 3 / 6 + zz ** 4 / 24
    Rimp = lambda zz: 1 / (1 - zz)
    hs = np.geomspace(0.2, 0.01, 16)

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(hs)), len(hs) - 1)
        h = hs[i]
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1, 1.25])
        ax1.contourf(z.real, z.imag, np.abs(R_exp) <= 1, levels=[.5, 1.5],
                     colors=[DANGER], alpha=.25)
        ax1.contour(z.real, z.imag, np.abs(R_exp), levels=[1], colors=[DANGER])
        ax1.plot([lam * h], [0], "o", color=NAVY, ms=6)
        ax1.set_xlim(-4, 1.2); ax1.set_ylim(-3, 3); ax1.grid(False)
        ax1.set_title(f"explicit stability region, λh = {lam*h:.2f}")
        ax1.set_xlabel("Re(λh)"); ax1.set_ylabel("Im(λh)")
        te, ye = march(Rexp, h); ti, yi = march(Rimp, h)
        ax2.plot(tt, exact, color=INK, lw=2.6, alpha=.25, label="exact")
        ax2.plot(te, ye, "o-", color=DANGER, ms=3, label="explicit-stage loss")
        ax2.plot(ti, yi, "o-", color=ACCENT, ms=3, label="implicit-stage loss")
        ax2.set_ylim(-1.5, 1.5); ax2.set_xlabel("t"); ax2.legend(fontsize=6.8)
        ax2.set_title(f"time-discrete PINN step h = {h:.3f}")

    animate("q26_rkpinn", draw, n_frames=34, figsize=(7.5, 2.9))
    return record("q26", stable_h=float(2.78 / abs(lam)))

    noisy data -- then check identifiability with a profile-likelihood sweep.
    A flat profile means the data cannot pin the parameter down."""

    k_true, d_true = 1.6, 0.7

    def model(k, d, t):
        return k / (k - d) * (np.exp(-d * t) - np.exp(-k * t)) if abs(k - d) > 1e-9 else t * np.exp(-d * t)
    tt = np.linspace(0, 6, 300)

def sim28_grayblack_crossover():
    """AI-Aristotle's gray-box pipeline in miniature: (1) fit the state from
    sparse noisy data with a physics-regularised least-squares network,
    (2) subtract the known physics to expose the *missing* term, (3) recover a
    closed form for it by sparse symbolic regression over a small library."""
    rng = np.random.default_rng(53)
    k_known = 2.0
    tt = np.linspace(0, 4, 400)
    true_missing = 1.5 * np.sin(3 * tt)
    y0 = 0.4
    y = np.zeros_like(tt)
    y[0] = y0
    for i in range(len(tt) - 1):                          # reference trajectory
        h = tt[i + 1] - tt[i]
        f = lambda s, v: -k_known * v + 1.5 * np.sin(3 * s)
        k1 = f(tt[i], y[i]); k2 = f(tt[i] + h / 2, y[i] + h / 2 * k1)
        k3 = f(tt[i] + h / 2, y[i] + h / 2 * k2); k4 = f(tt[i] + h, y[i] + h * k3)
        y[i + 1] = y[i] + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)

    lib_names = ["1", "t", "y", "y²", "sin t", "cos t", "sin 3t", "cos 3t"]
    stages = []
    for nd in [8, 12, 18, 26, 40, 60, 90]:
        td = np.linspace(0, 4, nd)
        yd = np.interp(td, tt, y) + rng.normal(0, .03, nd)
        rf = RandomFeatures(n_feat=80, scale=4.0, seed=91)
        A = np.vstack([rf.phi(td[:, None]), .004 * rf.d2phi(np.linspace(0, 4, 200)[:, None])])
        b = np.concatenate([yd, np.zeros(200)])
        w = lstsq(A, b, 1e-6)
        yh, dyh = rf.phi(tt[:, None]) @ w, rf.dphi(tt[:, None]) @ w
        missing = dyh + k_known * yh                       # what the known physics misses
        L = np.stack([np.ones_like(tt), tt, yh, yh ** 2, np.sin(tt), np.cos(tt),
                      np.sin(3 * tt), np.cos(3 * tt)], 1)
        c = lstsq(L, missing, 1e-8)
        for _ in range(8):                                 # sequential thresholding
            small = np.abs(c) < .25
            c[small] = 0
            if (~small).any():
                c[~small] = lstsq(L[:, ~small], missing, 1e-8)
        stages.append((nd, yh, missing, c.copy(), rel_l2(L @ c, true_missing)))

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(stages)), len(stages) - 1)
        nd, yh, missing, c, e = stages[i]
        ax1, ax2, ax3 = fig.subplots(1, 3, width_ratios=[1.1, 1.1, 1])
        td = np.linspace(0, 4, nd)
        ax1.plot(tt, y, color=INK, lw=2.4, alpha=.28, label="true state")
        ax1.plot(tt, yh, color=ACCENT, lw=1.4, label="gray-box fit")
        ax1.plot(td, np.interp(td, tt, y), "o", color=DANGER, ms=3.5, label=f"{nd} noisy points")
        ax1.set_xlabel("t"); ax1.legend(fontsize=6.4); ax1.set_title("state")
        ax2.plot(tt, true_missing, color=INK, lw=2.4, alpha=.28, label="true missing term")
        ax2.plot(tt, missing, color=BLUE, lw=1.2, label="$\\dot y + k y$ (extracted)")
        ax2.set_ylim(-3, 3); ax2.set_xlabel("t"); ax2.legend(fontsize=6.4)
        ax2.set_title("black-box residual")
        ax3.barh(lib_names, c, color=[ACCENT if abs(v) > .25 else "#cfd6da" for v in c])
        ax3.axvline(1.5, ls="--", color=DANGER, lw=1)
        ax3.set_xlim(-2, 2.4); ax3.set_title(f"symbolic terms (err {e:.2f})")

    animate("q28_crossover", draw, n_frames=30, figsize=(8.0, 2.8))
    return record("q28", coeff_sin3t=float(stages[-1][3][6]), err=stages[-1][4])

def sim30_illconditioning():
    """Ill-conditioning: differentiating the network squares the operator's
    condition number in the least-squares normal equations, so first-order
    methods stall. A quasi-Newton/second-order step fixes the same problem."""
    rf = RandomFeatures(n_feat=60, scale=8.0, seed=61)
    P = np.linspace(0, 1, 150)[:, None]
    A = rf.d2phi(P)
    f = -(3 * np.pi) ** 2 * np.sin(3 * np.pi * P[:, 0])
    Ab = 30 * rf.phi(np.array([[0.], [1.]]))
    M = np.vstack([A, Ab]); rhs = np.concatenate([f, [0, 0]])
    H = M.T @ M
    cond = np.linalg.cond(H)
    exact = np.sin(3 * np.pi * np.linspace(0, 1, 300))
    steps = 800
    eta = 1.0 / np.linalg.eigvalsh(H).max()
    w = np.zeros(60); adam_m = np.zeros(60); adam_v = np.zeros(60)
    e_gd, e_adam, e_newton = [], [], []
    w_gd = np.zeros(60)
    Xe = rf.phi(np.linspace(0, 1, 300)[:, None])
    for s in range(steps):
        g = 2 * (H @ w_gd - M.T @ rhs)
        w_gd = w_gd - eta * g / 2
        e_gd.append(rel_l2(Xe @ w_gd, exact))
        g2 = 2 * (H @ w - M.T @ rhs)
        adam_m = .9 * adam_m + .1 * g2
        adam_v = .999 * adam_v + .001 * g2 ** 2
        w = w - 2e-2 * (adam_m / (1 - .9 ** (s + 1))) / (np.sqrt(adam_v / (1 - .999 ** (s + 1))) + 1e-8)
        e_adam.append(rel_l2(Xe @ w, exact))
        if s < 12:                      # Newton / L-BFGS-like phase after Adam
            wn = np.linalg.solve(H + 1e-10 * np.eye(60) * (12 - s), M.T @ rhs)
            e_newton.append(rel_l2(Xe @ wn, exact))
    e_newton = e_adam[:120] + [e_newton[-1]] * (steps - 120)

    def draw(fig, k, n):
        m = max(int(ease(k, n) * steps), 5)
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1, 1.2])
        ev = np.linalg.eigvalsh(H)[::-1]
        ax1.semilogy(ev / ev[0], color=NAVY)
        ax1.set_xlabel("index"); ax1.set_ylabel("normalised eigenvalue")
        ax1.set_title(f"Gauss-Newton spectrum, κ ≈ {cond:.1e}")
        ax2.semilogy(e_gd[:m], color=MUTED, label="gradient descent")
        ax2.semilogy(e_adam[:m], color=DANGER, label="Adam")
        ax2.semilogy(e_newton[:m], color=ACCENT, label="Adam → second-order")
        ax2.set_xlim(0, steps); ax2.set_ylim(1e-8, 3)
        ax2.set_xlabel("iteration"); ax2.set_ylabel("relative $L_2$")
        ax2.legend(); ax2.set_title("under-optimisation, not under-expressivity")

    animate("q30_illcond", draw, n_frames=36, figsize=(7.5, 2.9))
    return record("q30", cond=float(cond), adam=e_adam[-1], newton=e_newton[-1])

The problem

Deeper physics-informed networks trained worse than shallow ones, the opposite of the scaling behaviour seen everywhere else in deep learning.

Approach

PirateNets attribute this to a pathological initialisation: at depth, the network's initial function is already far from anything useful and the physics-informed loss cannot recover. What the paper reports

def sim32_depth():

    because the initial function is already far from the data. A residual
    adaptive connection starts the deep model at the shallow model's answer."""
    x = np.linspace(0, 1, 300)
    target = np.sin(3 * np.pi * x) * np.exp(-x)
    rng = np.random.default_rng(71)

    def deep_features(depth, alpha, seed=0):
        r = np.random.default_rng(seed)
        h = np.tanh(x[:, None] * r.normal(0, 6, 60) + r.uniform(-3, 3, 60))

def sim33_multiplicity():
    """Solution multiplicity (deep-ensemble checks). The Bratu problem
    u'' + lambda e^u = 0, u(0)=u(1)=0 has an exact two-parameter family:
    u(x) = -2 ln[ cosh(theta(x-1/2)/2) / cosh(theta/4) ] with
    theta = sqrt(2 lambda) cosh(theta/4). Below lambda_c that equation has TWO
    roots, so two different fields have exactly zero residual; above it, none."""
    lam_c = 3.513830719
    x = np.linspace(0, 1, 400)

    def theta_roots(lam):
        g = lambda th: th - np.sqrt(2 * lam) * np.cosh(th / 4)
        grid = np.linspace(1e-6, 40, 40000)
        v = g(grid)
        sign = np.where(np.sign(v[:-1]) != np.sign(v[1:]))[0]
        out = []
        for i in sign:                                  # bisection on each bracket
            a, b = grid[i], grid[i + 1]
            for _ in range(80):
                m = .5 * (a + b)
                if np.sign(g(a)) == np.sign(g(m)):
                    a = m
                else:
                    b = m
            out.append(.5 * (a + b))
        return out

    def field(th):
        return -2 * np.log(np.cosh(th * (x - .5) / 2) / np.cosh(th / 4))

    lams = np.linspace(0.2, 3.9, 30)
    lower, upper = [], []
    for lam in lams:
        r = theta_roots(lam)
        lower.append(field(r[0]).max() if len(r) > 0 else np.nan)
        upper.append(field(r[1]).max() if len(r) > 1 else np.nan)

    def resid(th, lam):
        u = field(th)
        h = x[1] - x[0]
        d2 = (u[2:] - 2 * u[1:-1] + u[:-2]) / h ** 2
        return float(np.abs(d2 + lam * np.exp(u[1:-1])).max())

    def draw(fig, k, n):
        i = min(int(ease(k, n) * len(lams)), len(lams) - 1)
        ax1, ax2 = fig.subplots(1, 2, width_ratios=[1.2, 1])
        ax1.plot(lams[:i + 1], lower[:i + 1], "o-", color=ACCENT, ms=3, label="lower branch")
        ax1.plot(lams[:i + 1], upper[:i + 1], "o-", color=DANGER, ms=3, label="upper branch")
        ax1.axvline(lam_c, ls="--", color=MUTED)
        ax1.text(lam_c - .06, 7.8, "$\\lambda_c$", color=MUTED, ha="right")
        ax1.set_xlim(0, 4); ax1.set_ylim(0, 9)
        ax1.set_xlabel("λ"); ax1.set_ylabel("$\\max\\,u$"); ax1.legend(loc="upper left")
        ax1.set_title("two solutions below $\\lambda_c$, none above")
        lam = lams[i]
        r = theta_roots(lam)
        if r:
            ax2.plot(x, field(r[0]), color=ACCENT,
                     label=f"branch A (residual {resid(r[0], lam):.0e})")
        if len(r) > 1:
            ax2.plot(x, field(r[1]), color=DANGER,
                     label=f"branch B (residual {resid(r[1], lam):.0e})")
        ax2.set_ylim(0, 9); ax2.set_xlabel("x"); ax2.legend(fontsize=6.6, loc="upper left")
        ax2.set_title(f"λ = {lam:.2f}: which one did your PINN find?")

    animate("q33_multiplicity", draw, n_frames=32, figsize=(7.5, 2.9))
    return record("q33", lam_c=lam_c, n_below=int(np.sum(~np.isnan(upper))))

def sim34_spurious_pseudotime():
    """When PINNs go wrong: an explicit construction of a *spurious* solution.
    u_spur = u_true + bump(x) * prod_i (x - x_i) vanishes at every collocation
    point, so the empirical residual is ~0 while the function is wrong in
    between. Adaptive pseudo-time stepping with resampling exposes it."""
    xc = np.linspace(0.05, 0.95, 11)               # fixed collocation set
    x = np.linspace(0, 1, 600)
    u_true = np.sin(2 * np.pi * x)

    def bump(z, amp):
        p = np.ones_like(z)
        for xi in xc:
            p = p * (z - xi)
        return amp * p / (np.abs(np.prod(0.5 - xc)) + 1e-12)
    amps = np.linspace(0, .9, 12)
    rng = np.random.default_rng(83)
    resampled = [np.sort(rng.uniform(0, 1, 11)) for _ in range(12)]

    def draw(fig, k, n):
        p = ease(k, n)
        stage = min(int(p * 2), 1)                 # phase 1: deception, phase 2: resampling
        j = int((p * 2 - stage) * (len(amps) - 1))
        amp = amps[j] if stage == 0 else amps[-1]
        u_sp = u_true + bump(x, amp)
        ax1, ax2 = fig.subplots(2, 1, height_ratios=[1.7, 1], sharex=True)
        ax1.plot(x, u_true, color=INK, lw=2.6, alpha=.25, label="true solution")
        ax1.plot(x, u_sp, color=DANGER, lw=1.5, label="low-residual spurious solution")
        pts = xc if stage == 0 else resampled[j]
        ax1.plot(pts, np.interp(pts, x, u_sp), "o", color=ACCENT, ms=5,
                 label="collocation points")
        ax1.set_ylim(-2.2, 2.2); ax1.legend(fontsize=6.8, ncol=3, loc="lower center")
        ax1.set_title("fixed collocation set" if stage == 0
                      else "pseudo-time step → resample: the defect becomes visible")
        emp = np.abs(np.interp(pts, x, u_sp) - np.interp(pts, x, u_true))
        ax2.semilogy(x, np.abs(u_sp - u_true) + 1e-12, color=DANGER, lw=1.1,
                     label="true pointwise error")
        ax2.semilogy(pts, emp + 1e-12, "o", color=ACCENT, ms=5, label="error seen by the loss")
        ax2.set_ylim(1e-13, 5); ax2.set_xlabel("x"); ax2.legend(fontsize=6.6, ncol=2)

    animate("q34_spurious", draw, n_frames=44, figsize=(7.2, 3.3))

Thematic failure-mode analysis

Optimisation pathologies: loss imbalance, gradients, and landscapes

The central optimisation failure is that PINNs optimise a composite objective. PDE residual, boundary terms, initial terms, data terms, and sometimes parameter priors, whose components can have incompatible scales and convergence rates. Basir and Rathore et al. strengthened this from two directions: Basir visualised highly non-convex loss surfaces and the scale mismatch between boundary and domain terms, while Rathore et al. tied PINN difficulty to ill-conditioning induced by differential operators and showed second-order methods can improve hard cases. Sections 19, 22 and 30 measure all three effects directly.

Spectral bias and multiscale failure

Coordinate MLPs tend to learn smooth, low-frequency structure before high-frequency or sharp-gradient components, which is damaging for waves, reaction–diffusion fronts, turbulence, and multiscale dynamics. Fourier features and PirateNets are the two responses: Fourier embeddings alter the NTK eigenspectrum so multiscale structure is representable in fast-converging directions, while PirateNets use residual adaptive connections so deeper physics-informed networks train stably rather than degrading with depth (§20, §32).

Stiffness and error propagation in ODEs and chaotic systems

In ODEs, stiffness turns derivative-residual minimisation into a poor surrogate for stable time integration, because the optimiser does not inherit the adaptive step-size or stability properties of classical solvers. In chaotic systems, early-time errors contaminate later dynamics; causal training addresses this by forcing time segments to be learned in physical order, and pseudo-time/resampling methods later reframed part of the problem as avoiding spurious attractors in residual space (§23, §24, §26).

Sampling failures and residual blind spots

PINNs evaluate PDE residuals on finite collocation sets; poor or fixed sampling can miss narrow high-residual layers and produce propagation failure. The 2026 spurious-solution paper makes the blind spot sharper: for a fixed finite collocation set, smooth functions can satisfy the training constraints at those points while becoming physically trivial elsewhere, so empirical residual minimisation alone is not a correctness certificate. The experiments in §21 and §34 exhibit both cases with the residual pinned at machine zero.

Identifiability and inverse-problem ambiguity

Systems biology highlights a domain-specific failure mode: even if a network fits sparse, noisy observations and the ODE residual, the parameters may be structurally or practically unidentifiable. AI-Aristotle further shows that data size changes which method is preferable. PINNs can be strong for sparse/noisy small-data settings, while X-TFC improves with larger datasets and greater computational efficiency because it avoids back-propagation-heavy training in some cases (§27, §28).

The most important difference is that ODE failures often look like instability or parameter ambiguity, while PDE failures often look like spatially localised residual loopholes, unresolved discontinuities, or physically wrong fields with deceptively low training loss. The most important commonality is that both ODEs and PDEs expose the weakness of treating a physical law as a single scalar penalty optimised by generic gradient descent.

Open problems and forward-looking conclusion

The remaining open problem is certification: the field still needs diagnostics that distinguish “low empirical residual” from “physically correct solution”, especially under finite collocation, shocks, non-unique weak solutions, and inverse identifiability constraints. Benchmarks such as PINNacle and comparative studies against FEM are essential because they expose where methods work, where they merely evaluate quickly after costly training, and where classical numerical methods remain superior.

The field's likely direction is not one universal PINN but hybrid scientific learning pipelines: causal residual schedules for time evolution, adaptive sampling for hidden residual layers, integral and weak formulations for stiffness, architecture modifications for multiscale functions, optimisation methods for ill-conditioning, identifiability checks for inverse problems, and residual reformulations such as pseudo-time stepping for spurious solutions.

In that sense the 2022–2026 legacy is a maturation from enthusiasm about mesh-free residual minimisation toward a more numerical-analysis-aware view: a PINN is reliable only when the training formulation, sampling, optimisation, and validation procedure jointly respect the physics and the numerical structure of the problem.

A practical checklist

Report the residual and an independent error measure; resample collocation points and re-check; balance loss terms from gradient or curvature statistics; respect causality for evolution problems; use an integral or time-discrete form when stiff; run an ensemble when the problem is nonlinear; and profile the likelihood before quoting a fitted parameter.

Cross-paper discussion

The papers do not propose one linear sequence of universally improving solvers. They attack different failure modes:

  • Representation: DPINN, cPINN and XPINN partition difficult targets; DeepONet changes the task from function approximation to operator approximation.
  • Residual formulation: the original PINN uses strong-form pointwise penalties; VPINN uses weak residuals; NeuralPDE studies integral discretization; DeepXDE/RAR adapts collocation.
  • Optimization: NTK analysis explains unequal convergence rates; adaptive weighting and optimizer staging attempt to correct them.
  • Physical difficulty: Stiff-PINN reduces physical stiffness; high-speed-flow PINNs need discontinuity-aware sampling and remain weaker for forward shock capture.
  • Uncertainty: adversarial PINNs, NN-aPC/dropout and B-PINNs address different uncertainty sources and inference costs.
  • Scalability: PPINN decomposes time; cPINN/XPINN decompose space-time; DeepONet pays a large offline cost for fast repeated online inference.

Final conclusions

  1. The original PINN is best viewed as a flexible constrained regression framework, not a replacement that dominates mature numerical solvers on every forward problem.
  2. The strongest early advantages appear in inverse problems, sparse-data fusion, and reusable operator surrogates.
  3. Domain decomposition is conditional: it helps when local simplification outweighs reduced data per subnet.
  4. Adaptive sampling and variational residuals improve where and how physics is enforced, but they cannot repair an incorrect model.
  5. Physical stiffness and optimization stiffness are distinct. Stiff-PINN addresses the former through model reduction; NTK-based methods address the latter through training dynamics.
  6. Uncertainty methods differ materially: dropout, polynomial chaos, adversarial inference and Bayesian posterior sampling should not be treated as interchangeable.
  7. Reproducible review work should report error, runtime, sampling, model size, optimizer, random seeds, and whether a result is a faithful reproduction or a pedagogical proxy.

Recovering Rate Constants from 14 Sparse Measurements

01 — The Problem

Rate Constants from 14 Sparse Concentration Measurements

The sequence $A \to B \to C$ is the workhorse template across pharmaceutical chemistry. In API synthesis the intermediate $B$ may be the target compound and you want to quench at peak $[B]$. In drug stability studies $B$ is often a toxic degradant. In metabolic modelling $B$ is an active metabolite. In every case the governing ODE system is:

$$\frac{dC_A}{dt} = -k_1 C_A, \qquad \frac{dC_B}{dt} = k_1 C_A - k_2 C_B, \qquad \frac{dC_C}{dt} = k_2 C_B$$

The analytical solution (valid when $k_1 \ne k_2$) is:

$$C_A(t) = C_{A,0}\,e^{-k_1 t}, \quad C_B(t) = C_{A,0}\frac{k_1}{k_2 - k_1}\!\left(e^{-k_1 t} - e^{-k_2 t}\right), \quad C_C(t) = C_{A,0}\!\left[1 - \frac{k_2\,e^{-k_1 t} - k_1\,e^{-k_2 t}}{k_2 - k_1}\right]$$

The intermediate peak occurs at $t^* = \ln(k_1/k_2)/(k_1 - k_2)$. A 10 % error in the ratio $k_1/k_2$ shifts $t^*$ measurably — which can change a quench decision or a shelf-life projection. The inverse problem: recover both constants from 14 noisy measurements.

02 — The Gradient Flow Behind k₁ and k₂

How PINN Training Actually Recovers Rate Constants

Most expositions skip this. Understanding how backpropagation reaches the rate constants is essential for debugging failures and extending to more complex systems.

Softplus parameterisation — enforcing positivity

Rate constants must be strictly positive. Optimising $k_i$ directly risks crossing zero during gradient steps, which collapses the ODE residual. The standard fix is to store unconstrained scalars $\tilde{k}_i$ and apply:

$$k_i = \mathrm{softplus}(\tilde{k}_i) = \ln\!\left(1 + e^{\tilde{k}_i}\right)$$

Initialised at $\tilde{k}_i = 0$, this gives $k_i(0) = \ln 2 \approx 0.693$ — within one order of magnitude of most pharmaceutical rate constants. The softplus is smooth everywhere so gradients flow freely. The gradient gate is $\partial k_i / \partial \tilde{k}_i = \sigma(\tilde{k}_i)$ (logistic sigmoid), which is bounded away from zero for finite $\tilde{k}_i$.

The composite loss and its gradient pathways

$$\mathcal{L} = \underbrace{\frac{1}{N_d}\sum_{i}\bigl\|\hat{\mathbf{C}}(t_i) - \mathbf{C}_i^{\text{obs}}\bigr\|^2}_{\mathcal{L}_d} + \;\lambda_p\underbrace{\frac{1}{N_c}\sum_{j}\!\left(r_A^2 + r_B^2 + r_C^2\right)}_{\mathcal{L}_p} + \underbrace{\bigl\|\hat{\mathbf{C}}(0) - \mathbf{C}_0\bigr\|^2}_{\mathcal{L}_{\text{IC}}}$$

where the ODE residuals (evaluated at collocation points, no integrator) are:

$$r_A = \dot{\hat{C}}_A + k_1\hat{C}_A, \quad r_B = \dot{\hat{C}}_B - k_1\hat{C}_A + k_2\hat{C}_B, \quad r_C = \dot{\hat{C}}_C - k_2\hat{C}_B$$

Autograd computes the exact gradient of the physics loss with respect to each rate constant:

$$\frac{\partial \mathcal{L}_p}{\partial k_1} = \frac{2}{N_c}\sum_j\left[r_A^{(j)}\hat{C}_A^{(j)} - r_B^{(j)}\hat{C}_A^{(j)}\right], \qquad \frac{\partial \mathcal{L}_p}{\partial k_2} = \frac{2}{N_c}\sum_j\left[r_B^{(j)}\hat{C}_B^{(j)} - r_C^{(j)}\hat{C}_B^{(j)}\right]$$

Read this intuitively: if $k_1$ is too large, $r_A > 0$ everywhere (the predicted decay is faster than the physics residual tolerates). The gradient $\partial \mathcal{L}_p/\partial k_1 \propto \sum r_A \hat{C}_A > 0$ pushes $k_1$ downward. The data loss reinforces this: if measured $C_A$ decays slower than the model, $\partial \mathcal{L}_d/\partial k_1$ also drives $k_1$ down. Both channels converge to the same fixed point.

Even without $C_B$ in the data loss, the physics residuals reconstruct it from $C_A$ and $C_C$ alone: $r_B = 0 \Rightarrow \dot{C}_B = k_1 C_A - k_2 C_B$, fully determined once $k_1, k_2$ are known from the other two species. This redundancy is the source of noise robustness.

03 — Ji et al. (2021) Stiff-PINN

Recreating the Canonical Benchmark

Ji, W., Qiu, W., Shi, Z., Pan, S. & Deng, S. (2021). Stiff-PINN: Physics-Informed Neural Network for Stiff Chemical Kinetics. J. Phys. Chem. A 125(36):8098–8106. doi:10.1021/acs.jpca.1c05102

Ji et al. used A→B→C as their non-stiff validation baseline before tackling stiff chemical networks with stiffness ratios up to $\kappa = k_{\max}/k_{\min} = 10^6$. Their central claim: PINNs recover rate constants in a single differentiable computation — no outer optimisation loop, no repeated integrator calls.

What makes a system stiff, and why it matters

Stiffness is a property of the Jacobian eigenvalues. For A→B→C the eigenvalues are $\{-k_1, -k_2\}$. When $k_1 \gg k_2$ (e.g., $k_1 = 100, k_2 = 0.001$, stiffness ratio $\kappa = 10^5$):

  • Explicit solvers (RK45): stability requires step size $h < 2/k_1$. For $k_1 = 100$ the maximum step is $h = 0.02$, so reaching $t = 10$ needs at least 500 steps regardless of how smooth the slow dynamics are. Cost scales as $O(\kappa)$.
  • Implicit solvers (Radau, LSODA): unconditionally stable but each step requires solving a nonlinear system — $O(n^3)$ Jacobian factorisation per species. Fast for small $n$, expensive for large reaction networks.
  • PINN: no step-size constraint because there is no time integration. The stiff timescale manifests as a steep gradient in the loss landscape, not a stability constraint on the solver. The cost of encoding a $\kappa = 10^5$ stiff system is essentially the same as a $\kappa = 1$ system.

QSSA regularisation for fast-slow decomposition

For very stiff systems Ji et al. add a quasi-steady-state assumption penalty in the fast-timescale region $t > t_{\text{fast}}$ (after species B has had time to relax):

$$\mathcal{L}_{\text{QSSA}} = \left\|\hat{C}_B(t) - \frac{k_1 \hat{C}_A(t)}{k_2}\right\|^2_{t\, >\, t_{\text{fast}}}$$

This is a soft algebraic constraint — it penalises solutions where B deviates from pseudo-steady state in the slow-dynamics regime. For the non-stiff benchmark ($\kappa = 1.67$) this term is unnecessary; the standard physics loss is sufficient.

Benchmark result (notebook output) 14 noisy measurements, 2 % Gaussian noise added to analytical solution. Adam 12,000 epochs + L-BFGS 500 steps. Recovered: $k_1 = 1.003$ (true 1.0, error 0.3 %), $k_2 = 0.598$ (true 0.6, error 0.3 %). Mass conservation $C_A + C_B + C_C = 1$ satisfied to <0.1 % across the entire domain with no explicit constraint added.
04 — SPIN-ODE (2025)

Extending to Higher-Order and Reversible Reactions

SPIN-ODE (2025) — Sparse Physics-Informed Networks for ODE Parameter Estimation — extends the Ji et al. framework to problems where the reaction mechanism itself is unknown.

Higher-order kinetics: learning reaction orders

For a general power-law rate $r = k[A]^m[B]^n$, both the rate constant $k$ and the orders $m, n$ may be unknown. SPIN-ODE makes all parameters trainable simultaneously:

$$\frac{dC_A}{dt} = -k_1 C_A^{m_1}, \quad k_i = \mathrm{softplus}(\tilde{k}_i), \quad m_i = 3\,\sigma(\tilde{m}_i) \in (0, 3)$$

A sparsity penalty drives $m_i$ toward integer values (automatic mechanism selection):

$$\mathcal{L}_{\text{sparse}} = \lambda_s \sum_i \min_{p \in \{0,1,2,3\}} |m_i - p|$$

Reversible consecutive reactions

A realistic pharmaceutical system often has partial reversibility. For $A \underset{k_{-1}}{\stackrel{k_1}{\rightleftharpoons}} B \underset{k_{-2}}{\stackrel{k_2}{\rightleftharpoons}} C$, four rate constants must be identified from the same sparse measurements:

$$\frac{dC_A}{dt} = -(k_1 C_A - k_{-1} C_B), \quad \frac{dC_B}{dt} = k_1 C_A - k_{-1} C_B - k_2 C_B + k_{-2} C_C$$

Thermodynamic consistency requires $k_1 k_2 / (k_{-1} k_{-2}) = K_{eq}$. When $K_{eq}$ is known from calorimetry, SPIN-ODE encodes it as a hard constraint on the parameter vector:

$$\mathcal{L}_{K_{eq}} = \left(\frac{k_1 k_2}{k_{-1} k_{-2}} - K_{eq}^{\text{known}}\right)^2$$

This is physics-informed regularisation at the parameter level — it encodes the second law of thermodynamics as a soft constraint on the rate constant manifold, reducing the effective degrees of freedom and improving identifiability from sparse data.

05 — Classical Alternative

Nonlinear Least Squares + ODE Solver: A Complete Treatment

Mathematical formulation

$$\hat{\theta} = \arg\min_{\theta = (k_1,\, k_2)} \sum_{s \in \{A,B,C\}} \sum_{i=1}^{n_s} w_s\,\bigl(\phi_s(t_i;\theta) - C_s^{\text{obs},i}\bigr)^2$$

where $\phi_s(t;\theta)$ is the ODE solution (from a numerical integrator) and $w_s$ are species weights. The Levenberg-Marquardt algorithm iterates:

$$\theta^{(n+1)} = \theta^{(n)} - \bigl(J^\top J + \mu I\bigr)^{-1} J^\top \mathbf{r}(\theta^{(n)})$$

where $J_{ij} = \partial r_i / \partial \theta_j$ is the residual Jacobian. Computing $J$ requires the sensitivity equations:

$$\frac{d}{dt}\frac{\partial \mathbf{C}}{\partial k_j} = J_{\mathbf{f}}(t,\mathbf{C})\,\frac{\partial \mathbf{C}}{\partial k_j} + \frac{\partial \mathbf{f}}{\partial k_j}, \quad \left.\frac{\partial \mathbf{C}}{\partial k_j}\right|_{t=0} = \mathbf{0}$$

For A→B→C, each sensitivity evaluation adds $2 \times 3 = 6$ equations to the $n=3$ state equations. Alternatively, finite differences use $2p$ additional ODE solves per Jacobian evaluation ($p = 2$ here). Either way the cost per LM iteration is $3–5\times$ the base ODE solve.

The log-transform $k_i = e^{\theta_i}$ is the NLS counterpart of softplus. Both enforce positivity; the log-transform is more common in classical statistics because it simplifies uncertainty quantification: log-normal confidence intervals arise naturally from the asymptotic covariance $\Sigma = (J^\top J)^{-1} \hat{\sigma}^2$.

Practical rule of thumb For $n \le 5$ species and $p \le 4$ known-mechanism parameters: NLS+Radau is faster and gives exact covariance estimates. Reach for PINN/SPIN-ODE when: the mechanism is uncertain, the system is stiff with $\kappa > 10^3$ and you need GPU-scale parallelism, or you want to fuse sparse concentration data with thermodynamic constraints simultaneously.

Mathematical equivalence at the optimum

For well-posed problems with Gaussian noise, both PINN and NLS converge to the same maximum-likelihood estimate. The difference is the information pathway: NLS computes the sensitivity $\partial \phi_s/\partial \theta$ of the ODE flow (exact, requires integration); PINN computes the residual gradient $\partial r_j / \partial k$ at collocation points (exact, via autograd). These are related by the implicit function theorem — they carry the same information for smooth ODEs. PINN's advantage emerges when numerical integration is unstable (stiff) or expensive (PDEs).

Accuracy vs data sparsity (notebook experiment)

The notebook runs both methods at $N_d \in \{4, 8, 14, 20, 40\}$ with 50 noise realisations per setting:

  • $N_d \ge 8$: Both methods recover $k_1, k_2$ to within 1 %. PINN needs at minimum 6 data points (IC + 1 interior per species) for unique identification.
  • $N_d = 4$ (extremely sparse): PINN degrades gracefully — the physics residual acts as Tikhonov regularisation. NLS variance explodes because the Jacobian system becomes rank-deficient.
  • Bias under noise: Both estimators are approximately unbiased. At $N_d = 40$, PINN achieves lower variance than NLS because the physics constraint acts as prior knowledge on the parameter manifold.

Why PINNs fail at extrapolation

Networks trained on $[0, T]$ learn a spectral decomposition of that interval. Beyond $T$, the Fourier modes that fit the training data do not extrapolate — they oscillate wildly. For pharmaceutical stability models requiring 18-month projections from 6-month ICH data, this is a critical limitation. The engineering workaround: recover $k_1, k_2$ using PINN, then hand the parameters to a conventional ODE integrator for long-horizon simulation. The PINN is the parameter estimator, not the predictor.

The three-tier hybrid strategy

  1. Parameter identification: PINN or SPIN-ODE. Better noise robustness at sparse data, handles stiffness, recovers unknown mechanisms.
  2. Long-horizon trajectory prediction: Once $\hat{k}_1, \hat{k}_2$ are recovered, pass them to a conventional integrator (RK45 or Radau) for extrapolation. Do not rely on the PINN network itself.
  3. High-throughput IC screening: Train a DeepONet over the recovered $k_1, k_2$ distribution. One trained operator handles thousands of initial conditions without retraining — ideal for formulation screening or patient-specific dosing simulations.
08 — Implementation

Code: Multi-Output PINN, NLS Baseline, and SPIN-ODE Extension

The minimal PINN implementation that reproduces the Ji et al. benchmark:

Python · PyTorch — PINN inverse solver
# Rate constants live inside the computation graph
raw_k1 = nn.Parameter(torch.tensor(0.0, device=device))  # k1 = softplus(0) ≈ 0.693
raw_k2 = nn.Parameter(torch.tensor(0.0, device=device))
sp = nn.Softplus()

def loss_fn(t_col, t_data, c_data, t0, c0):
    C = model(t_col)                         # shape: (N_c, 3)
    Ca, Cb, Cc = C[:,0:1], C[:,1:2], C[:,2:3]
    k1, k2 = sp(raw_k1), sp(raw_k2)
    rA = d_dt(Ca, t_col) + k1 * Ca           # ODE residual: no integrator
    rB = d_dt(Cb, t_col) - k1 * Ca + k2 * Cb
    rC = d_dt(Cc, t_col) - k2 * Cb
    l_phys = (rA**2 + rB**2 + rC**2).mean()
    l_data = (model(t_data) - c_data).pow(2).mean()
    l_ic   = (model(t0) - c0).pow(2).mean()
    return l_data + 0.5 * l_phys + l_ic

params = list(model.parameters()) + [raw_k1, raw_k2]  # k's trained with weights
opt = torch.optim.Adam(params, lr=4e-3)

The classical NLS counterpart (notebook Section 5):

Python · SciPy — NLS baseline
from scipy.integrate import solve_ivp
from scipy.optimize import least_squares

def abc_ode(t, C, k1, k2):
    Ca, Cb, Cc = C
    return [-k1*Ca, k1*Ca - k2*Cb, k2*Cb]

def residual(theta, t_obs, C_obs):
    k1, k2 = np.exp(theta)             # log-transform: same role as softplus
    sol = solve_ivp(abc_ode, [0, t_obs[-1]], [1,0,0],
                    args=(k1, k2), t_eval=t_obs,
                    method='RK45', rtol=1e-9, atol=1e-10)
    return (sol.y.T - C_obs).ravel()

result = least_squares(residual, x0=np.log([0.5, 0.5]),
                       args=(t_obs, C_obs), method='lm')
k1_nls, k2_nls = np.exp(result.x)
# Asymptotic covariance: (J^T J)^{-1} sigma^2
cov = np.linalg.pinv(result.jac.T @ result.jac) * result.cost / (len(result.fun) - 2)
k1_std = np.sqrt(cov[0,0]) * k1_nls  # delta method: std of log-transformed param

01, The Problem

Estimating Vmax and Km from a Single Progress Curve

Every drug metabolised by CYP450 enzymes, every enzymatic step in API synthesis, and every biocatalytic process follows Michaelis-Menten kinetics. The two parameters biochemists need are $V_{max}$ (maximum reaction velocity) and $K_m$ (substrate affinity). Getting them from a single experiment, watching substrate deplete over time, is the progress curve method, and it is harder than it looks.

The full mechanism generates a stiff ODE system. When the enzyme-substrate complex $ES$ forms much faster than it breaks down, the system has two vastly different timescales:

$$E + S \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} ES \overset{k_2}{\longrightarrow} E + P$$

With $k_1 = k_{-1} = 100$ mM$^{-1}$min$^{-1}$ and $k_2 = 0.6$ min$^{-1}$, $ES$ equilibrates at $t = 0.075$ min (4.5 seconds). Substrate depletes over 30 minutes. Stiffness ratio: 400:1. A plain PINN on the full system cannot resolve both timescales simultaneously.

02, The Paper: Ji et al. (2021) Stiff-PINN

Applying Domain Knowledge to Remove Stiffness Before Training

Ji, W., Qiu, W., Shi, Z., Pan, S. & Deng, S. (2021). Stiff-PINN: Physics-Informed Neural Network for Stiff Chemical Kinetics. J. Phys. Chem. A 125(36):8098–8106.

Ji et al.'s central result: a plain PINN on the full stiff system fails; applying the QSSA analytically first makes the PINN succeed. The QSSA (Michaelis & Menten 1913, Briggs & Haldane 1925) sets $d[ES]/dt pprox 0$, eliminating the fast variable and collapsing four coupled ODEs to one:

$$\frac{d[S]}{dt} = -\frac{V_{max}[S]}{K_m + [S]}, \qquad V_{max} = k_2 E_0, \qquad K_m = \frac{k_{-1}+k_2}{k_1}$$
03, PINN vs Classical Enzyme Kinetics

Why the Progress Curve Method Is More Practical Than Lineweaver-Burk

Python · PyTorch
# QSSA-reduced: dS/dt = -Vmax*S / (Km + S)
raw_V = nn.Parameter(torch.tensor(0.0, device=device))  # log-softplus parameterisation
raw_K = nn.Parameter(torch.tensor(0.0, device=device))

def loss_fn():
    S    = model(tau)
    dS   = torch.autograd.grad(S, tau, torch.ones_like(S), create_graph=True)[0] / Tn
    V, K = sp(raw_V), sp(raw_K)
    res  = dS + V * S / (K + S)        # Michaelis-Menten residual
    l_phys = torch.mean(res**2)
    l_data = torch.mean((model(t_data) - S_data)**2)
    l_ic   = (model(t0) - S0)**2
    return l_data + 0.2*l_phys + l_ic.squeeze(), l_data, l_phys
Actual notebook output30 noisy substrate measurements, 0.12 mM noise sigma, T = 30 min. The notebook first confirms QSSA is justified (ES peaks at t = 0.075 min). Adam (15,000 epochs) + L-BFGS (500 steps). Recovered: Vmax = 0.613 mM/min (true 0.600, error 2.2%), Km = 1.153 mM (true 1.006, error 14.6%). Vmax is tightly constrained; Km requires observations near saturation for sharp identification.
04, Drug Development Implications

CYP450 Clearance, IC50, and Why Km Identifiability Matters

In drug metabolism studies, the intrinsic hepatic clearance is $CL_{int} = V_{max}/K_m$. An error of 15% in $K_m$ propagates directly to a 15% error in clearance prediction, within typical variability for a single progress curve experiment. For more precise estimates, three options: (1) run the experiment at multiple substrate concentrations, (2) run multiple replicates and fit jointly, or (3) use PAT tools for more frequent substrate measurement in the $[S] \sim K_m$ window.

The QSSA condition $E_0 \ll K_m + S_0$ should always be verified computationally before applying this notebook, the code does this automatically by simulating the full stiff system and confirming $ES$ peaks within seconds.

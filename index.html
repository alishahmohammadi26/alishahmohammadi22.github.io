01 — About

Applied AI Engineer.
Agentic System Builder.
Trustworthy Data Architect.

I’m an applied AI engineer who came up through hard science — a Ph.D. in chemical engineering, then a decade turning models into deployed systems across pharmaceutical R&D. I now focus on building the tools that make scientific data trustworthy for AI: MCP servers, agentic pipelines, evaluation harnesses, and the deterministic connectors that let regulated enterprises adopt frontier AI without losing correctness or auditability.

I lead FAIR Data Strategy and Digital Connectivity at Takeda Pharmaceutical — delivering applied AI engineering across R&D data domains. I’ve shipped production agentic AI systems for ontology curation, built knowledge-graph-aligned data models for cell therapy, and created FAIR Studio, an industry-alliance product (Pistoia Alliance) that operationalizes FAIR assessment at scale in pharmaceutical R&D.

My engineering practice spans the full stack: writing typed, tested Python; designing MCP servers and agent tool schemas; building multi-agent LangGraph pipelines with human-in-the-loop controls; and instrumenting evaluation harnesses that measure correctness and catch hallucinations before a wrong answer reaches a scientist. The thesis: a plausible-looking answer that’s subtly wrong can be worse than no answer — so every system I build is designed to refuse rather than guess.

What I do now
  • Build MCP servers & agent tool APIs — typed, tested Python exposing scientific data to Claude as deterministic, callable tools.
  • Orchestrate multi-agent pipelines — LangGraph workflows with human-in-the-loop controls, deployed in regulated life sciences workflows.
  • Instrument evaluation harnesses — labeled Q&A sets, automated correctness scoring, hallucination detection, and refuse-rather-than-guess behaviors.
